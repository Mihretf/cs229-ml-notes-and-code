# 🚀 Machine Learning Study & Workspace Tracker

Welcome to my personal Machine Learning repository! This repo serves as a central hub for everything I am working on, including lecture notes, mathematical derivations, coding assignments, and deep dives into algorithms inspired by rigorous courses like Stanford's CS229.

---

## 📂 Repository Structure

```text
├── notes/                # Markdown notes on core ML theory, derivations, and concepts
├── psets/                # Solutions and code implementations for problem sets
├── src/                  # Practice scripts, algorithm implementations (e.g., Logistic Regression, GDA)
└── datasets/             # Local datasets used for testing and debugging models

```

---

## 📚 Core Topics Covered

### 1. Supervised Learning & Linear Models

* **Linear Regression:** Least Mean Squares (LMS), Probabilistic Interpretation (OLS & Gaussian noise), and Normal Equations.
* **Classification & Logistic Regression:** Decision boundaries, optimization stability, and debugging training loops.
* **Generalized Linear Models (GLMs):** Unifying exponential family distributions.

### 2. Generative Learning Algorithms

* **Gaussian Discriminant Analysis (GDA):** Modeling joint distributions $P(x|y)$ and $P(y)$ assuming multivariate normal distributions.
* **Naive Bayes:** Text classification and conditional independence assumptions.

### 3. Non-Linearity, Kernels, & Deep Learning

* **Feature Maps ($\phi(x)$):** Transforming inputs into higher-dimensional spaces for linear separability.
* **The Kernel Trick:** Avoiding explicit high-dimensional computations via inner products.
* **Deep Neural Networks:** Transitioning from manual feature engineering to automatic representation learning ($\phi_\beta$), backpropagation, and the "black box" nature of deep networks.

---

## 🛠️ Generalization & Optimization Notes

* **Bias-Variance Tradeoff:** Understanding high bias (underfitting) vs. high variance (overfitting) and how to address them using regularization or extra data.
* **Numerical Stability:** Debugging training failures, gradient explosions, and convergence criteria in iterative optimization algorithms.

---

## 💡 Goal of This Repo

To bridge the gap between heavy mathematical theory (derivations, matrix calculus, probability bounds) and practical implementation (Python, NumPy, scikit-learn), building a rock-solid foundation for advanced ML research and low-resource AI applications.
